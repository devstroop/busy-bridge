<span id="_Toc467659196" class="anchor"></span>Function – AccExistWithBalUnderThis

Defination: *Public Function AccExistWithBalUnderThis(p_GrpCode, p_Date, p_OpBal) As Boolean*

This function searches for all the accounts that exist under the specified parent group with some non-zero closing/Opening balance. If any one account is found with some non-zero closing/opening balance, this function returns True value else False value is returned.

<u>Input Parameters:</u>

p_GrpCode = Long Type; Account Group Code whose accounts to be searched

p_Date = Date Type; Date on which Balance is to be checked

p_OpBal = Boolean Type; If Opening Balance is to be checked then set this parameter value as True else False for closing balance to be checked.

<u>Return Value:</u>

Boolean Type ; returns True if any of the account is found with some non-zero opening/closing balance else False value is returned.

<span id="_Toc467659197" class="anchor"></span>Function – AccountingTranExistInTran2

Defination: *Public Function AccountingTranExistInTran2(p_RecType, p_StartDate, p_Enddate, p_CheckForUserControl) As Boolean*

This function will check that if any transaction exists in Tran2 table under the specified RecType. For Tran2 table, different entries for RecType exist. RecType is a field in Tran2 table that identifies the entry of a transaction. For e.g. In a Sale voucher different entries for a single transaction are saved in Tran2 table. If it is an Accounting entry then RecType=1; if it is an item entry then RecType = 2; if it is a Bill Sundry entry then RecType = 3.

<u>Input Parameters:</u>

p_RecType = Integer Type; Specify RecType for Tran2 table as 1 for Accounting Entry, 2 for Item Entry and 3 for Bill Sundry Entry.

p_StartDate = Date Type; Transactions to be picked for checking between Date range.

p_EndDate = Date Type; Transactions to be picked for checking between Date range.

p_CheckForUserControl = Boolean Type; Specify True if User Control for Master in Reporting is to be checked else False

<u>Return Value:</u>

Boolean Type ; returns True if any transaction is found with specified RecType else False value is returned.
